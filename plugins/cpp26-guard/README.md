# cpp26-guard

Keep C++26 code free of hand-written copies of definitions: reflection instead of enum-to-string switches, name tables, flag chains and key/member blocks, with concepts, import std, format and print and a comment policy. Skills, a pre-write advisory hook and tested lints with allowance files.

Install: `/plugin install cpp26-guard --marketplace wrocpp/claude-marketplace`

Status: scaffold, content in progress.
